# Spotify Streaming History Analysis

An end-to-end exploratory data analysis (EDA) of my personal Spotify streaming history spanning over 5 years. This project extracts, cleans, and analyzes raw JSON data using Python and visualizes listening habits, top artists, and historical trends using Power BI.


## 🎯 Project Objectives
* **Data Cleaning & Transformation:** Converting raw Spotify JSON exports into a structured, analysis-ready format.
* **Exploratory Data Analysis (EDA):** Identifying top artists, most-played tracks, and calculating total listening time.
* **Trend Analysis:** Mapping out how music preferences, artist loyalty, and listening volume evolved across different years.
* **Interactive Visualization:** Building a dynamic Power BI dashboard to present the data insights visually.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas (data manipulation), Matplotlib & Seaborn (static visualization)
* **Environment:** Jupyter Notebook / VS Code
* **BI Tool:** Power BI
* **Version Control:** Git & GitHub

## 📁 Repository Structure
* `Spotify - Data Analytics Project.ipynb`: The main Jupyter Notebook containing the Python code for data extraction, cleaning, and EDA.
* `.gitignore`: Configured to automatically block and exclude sensitive raw personal data.
* `spotify_cleaned_history.csv`: The exported, aggregated dataset generated by the Python script, used as the data source for Power BI.


## 🔒 Data Privacy Note
The raw Spotify `.json` and `.zip` files contain Personally Identifiable Information (PII) and device history. To maintain data privacy and security, these raw files have been explicitly ignored via the `.gitignore` file and are not hosted in this public repository. Only the aggregated, anonymized `.csv` output is utilized for the final dashboard.
